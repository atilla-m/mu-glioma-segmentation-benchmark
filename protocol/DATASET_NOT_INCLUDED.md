# Dataset availability

The raw MU-Glioma-Post imaging dataset is not duplicated in this repository. The
study uses the publicly distributed MU-Glioma-Post collection described in the
manuscript and protocol (TCIA DOI `10.7937/7K9K-3C83`).

The experimental inventory contains 594 eligible labeled timepoints from 203
patients after excluding two timepoints without a segmentation mask. The frozen
patient-grouped fold definitions are included under `protocol/splits/`.

The repository contains only the frozen patient identifiers and partitions
needed to document the experiment. It contains no local credentials, download
tokens, or unofficial copy of the source imaging dataset.
